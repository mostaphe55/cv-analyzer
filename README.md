## 📌 Project Title

**AI-Powered Resume Analyzer & Job Matcher**

---

## 📖 Project Description

An intelligent web application that analyzes CVs and resumes using Artificial Intelligence. The system reads the uploaded CV, scores it, provides smart improvement suggestions, matches the user with suitable job opportunities, and offers a real-time AI career assistant chatbot — all powered by LLaMA 3.3 AI model via Groq API.

## 🚀 How To Run The Project

### Requirements

- Node.js v18 or higher
- npm package manager

### Steps

**1. Clone the repository:**

```bash
git clone https://github.com/YOUR_USERNAME/cv-analyzer.git
cd cv-analyzer
```

**2. Install dependencies:**

```bash
npm install
```

**3. Run the development server:**

```bash
npm run dev
```
